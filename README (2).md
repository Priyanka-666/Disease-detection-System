# Food Security through Aquaculture – CSP Project

Complete Community Service Project website based on the handwritten outline.

## Project Structure (as per notes)

1. **Welcome Screen**  
   - RCE & APSCHE logo placeholders  
   - Dept. of CSE  
   - CSP Name  
   - Team Members (1–4)  
   - Mentor  
   - Academic Year  

2. **Page 1** – Purpose, Selected Village demographic details, Major income, Importance of the project  

3. **Page 2** – Food Security through Aquaculture  
   - Percentage / role of aquaculture in world food security  
   - Countries with major aquaculture  
   - How prawns are useful for the human body  

4. **Page 3** – Cultivation details  
   - Total aquaculture land (hectares)  
   - Average yield per season  
   - Prawn types (Vannamei & Black Tiger)  
   - Export quality cultivation  
   - Other related information  

5. **Page 4** – General diseases in Aquaculture  
   - Explanation  
   - Precautionary measures  
   - Medicines / recovery methods  

## Files

- `index.html` – All pages & content  
- `style.css` – Clean, responsive design + dark mode  
- `script.js` – Page navigation + theme toggle  

## How to Run

1. Open `index.html` in any modern browser (Chrome / Edge / Firefox).  
2. No server or installation required.  
3. Replace placeholder text (village name, member names, mentor, exact survey figures) with your real data.

## Features

- Fully responsive (mobile, tablet, desktop)  
- Dark / Light mode  
- Smooth page navigation  
- Semantic HTML  
- Pure HTML + CSS + Vanilla JS (no frameworks)
